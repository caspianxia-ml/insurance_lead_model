## 本轮执行的规则

1. 依原字段顺序读取 industry_category → industry_major_category → industry_medium_category；每个字段内，明确的 `>` 层级链与 `|/丨` 多值分隔保留原顺序。斜杠招聘标签不做猜测拆分。
2. 用标准名称或明确有效标准代码定位分类，先保留第一个可确认分类；后续相容分类可补充更细层级，后续冲突分类忽略并逐项记账。
3. “制造业／汽车制造业／橡胶制品业”输出门类C、大类36，中类未知，并记录后续橡胶分类被忽略。
4. 同名跨层级只有在标准树中唯一可确定时才向下归类。例如“房地产业”的K与70属于同一唯一大类分支，可确定大类70；“制造业”单独出现不能随意指定某个制造大类。
5. 不对招聘行业标签做模糊猜测；无法定位的部分保留未知。企业记录保留。输出标准门类／大类／中类／小类代码及名称、冲突标记、未知标记、逐项采用原因。

该优先级是用户确定的业务处理约定，并非已核实企业真实主业。源字段与原始值全部保留，便于回查。
