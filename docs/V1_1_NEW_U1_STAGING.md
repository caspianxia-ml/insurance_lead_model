## 输入与解析

新输入是 `V2_U1_SH_SZ_Welfare_Raw.json`。Workbench 导出包含未转义的文本控制字符，因此严格 JSON 解析失败；V1.1 读取器用 Python `json.load(strict=False)` 原样读取字符串，要求根节点为非空对象数组且所有记录字段集合一致。原文件保持只读，没有覆盖或转换。SHA-256、字节数、修改时间和依赖版本见本地 manifest。

校验得到 18,325 条、每条 51 字段；`sample_type` 全为 `U1`，`has_welfare_raw` 全为 1，目标地区为上海 13,511 条、苏州 4,814 条。进入 V1 清洗前仅在内存中把样本标记 `U1` 映射为其内部 `U`，不改业务字段或原始文件。
