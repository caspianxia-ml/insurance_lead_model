## 最近一次基线实验

清洗后沪苏 P 11,080 家，训练/固定留出为 8,864/2,216；最终 U1 11,407 家，LR 临时训练池/独立评价 U 为 4,562/6,845。P 五折样本外评分 8,864 家，U1 LR 折外评分覆盖全部 11,407 家。

| 模型 | 固定留出 Top 10% 捕获率 | 五折均值 | 五折最小–最大 |
| --- | ---: | ---: | ---: |
| Repeated Sampled-U LR | 28.5% | 30.5% | 30.1%–31.0% |
| Positive Similarity | 8.3% | 8.1% | 7.9%–8.5% |
| One-Class SVM | 8.3% | 8.4% | 7.7%–8.9% |
| Isolation Forest | 5.0% | 5.6% | 4.9%–6.9% |

指标是在 P＋独立 U 排名中的已观察 P 捕获率；不能解释为 U 的真实准确率、保险福利概率或业务转化率。五折均值为各折捕获率的算术平均。

## 目录与运行

`data/v2/raw/` 保存四份只读原始副本；`data/v2/interim/` 与 `data/v2/processed/` 预留后续处理；`reports/v2/` 保存完整本机登记与冻结核验。它们均由 Git 忽略。`sql/v2/20261020_1200/` 保留四段 SQL 及原文；代码、文档、Notebook 模板和合成测试可公开复查。

使用自有、获授权的数据并安装 `requirements.txt` 后，在项目根目录运行测试：

```bash
python3 -m unittest discover -s tests -v
```

已有实验入口拒绝覆盖运行编号。若重跑新沪苏 P＋U1 实验，可显式使用冻结路径：

```bash
python3 -m experiments.v2_local_v1_baseline --run-id <unused-run-id> --p data/v2/raw/V2_P_National_20261020_1200.csv --u1 data/v2/raw/V2_U1_20261020_1200.csv
```

GitHub 不附带业务数据，因此克隆仓库后不能直接复现企业级结果；可运行合成测试，并将已有汇总与登记哈希核对。
