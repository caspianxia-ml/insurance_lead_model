## 方案和对照

F0 为年龄、注册资本、参保人数、行业大类和企业类型。所有变换沿用旧代码；未加字段保持相同值。各次填充、标准化和编码仅在训练数据拟合。

| 方案 | 在哪个方案上增加 | 目的 |
|---|---|---|
| F1_size | F0＋企业规模 | 单独检验规模 |
| F1_industry | F0＋行业门类/中类 | 单独检验行业细分；采集差异诊断 |
| F1 | F0＋规模＋行业门类/中类 | 原 F1 全组合及相互影响 |
| F2_safe | F1_size＋实缴资本 | 单独检验实缴资本，作为地区/简介的固定参照 |
| F2_year | F2_safe＋参保报告年份 | 单独检验年份；缺失差异诊断 |
| F2 | F1＋实缴资本＋年份 | 保留原计划 F2 全组合，属含风险字段的诊断 |
| F3 | F2_safe＋统一地址省市 | 单独检验地区 |
| F4 | F2_safe＋简介有无 | 单独检验采集覆盖 |

原计划的分组链不够隔离单项作用，因此增加单项拆分；F3/F4 的固定无地区参照预先取 F2_safe，避免先把风险行业/年份字段混入。这里 safe 仅指未包含本次明确的行业层级/年份风险项，并非已证明公平、无采集偏差或可部署。

## 新字段核查与边界

P 的原地区字段优先业务标签，U 主要地址提取，不能直接用于公平比较。F3 两类企业统一从原注册地址解析省市，不使用已有 region 字段、Leads 标签或企业名。使用有限明确省市规则，无法解析保留缺失，不根据标签补齐。省市覆盖和未解析数量留档；本次不是地区外留出验证。

原始检查发现行业中类和参保年份在 Gold/U 的非缺失率相差较大；industry_category 在 P/U 中还存在行业层级混用。保留训练折内的原 20 个百分点缺失差异审计；这些字段明确作为诊断性暴露测试，不偷偷放开准入规则，也不因验证分数高就推荐入模。全缺失字段则停止运行。F1/F2 与拆分项清楚记录上述风险；F4 简介有无反映信息采集覆盖，不能解释为真实福利证据。

年份只接受四位有效年份或导出浮点表示，范围 1900–2026，不接受未来年；零和无效值记为缺失。简介标志严格仅接受 0/1。外币、金额单位、负值处理及年龄参照日仍沿用旧规则。来源、标签、企业名、信用代码、打标详情与业务核验信息不作特征。
